# LuminaChat
LuminaChat | لومینا چت آسان پرتابل با php و sqlite برای دوستان | Easy portable chat with php and sqlite for friends

کافی است پروژه را به صورت فایل zip دانلود کنید و در هاست یا سرور لینوکس خود آن را استخراج کنید. نیازی به هیچ نصب و تنظیم نیست! چتروم شما برای ساخت گروه و اشتراک پیام متن و محتوا با دوستان حاضر است!
به راهنمای فایل help.txt عمل کنید و سپس برای امنیت بیشتر آن را پاک کنید.
