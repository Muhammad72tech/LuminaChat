# لومینا چت | LuminaChat

**یک چتروم و پیام‌رسان سبک، پرتابل و خودمیزبان (Self-Hosted) مبتنی بر PHP و SQLite**

<p style="text-align:center;width:100%;"><img src="/art/preview.png" alt="LuminaChat PHP"></p>

لومینا چت یک پلتفرم متن‌باز برای چت، پیام‌رسانی و ارتباط گروهی است که با PHP و SQLite ساخته شده است. این پروژه برای افرادی طراحی شده که به دنبال راهکاری ساده، سبک و مستقل برای ایجاد چتروم، پیام‌رسان خصوصی یا فضای ارتباطی گروهی هستند.
بدون نیاز به نصب، بدون نیاز به MySQL و بدون نیاز به پیکربندی پیچیده؛ کافی است فایل‌های پروژه را روی هاست، سرور لینوکس، VPS یا شبکه محلی خود استخراج کنید و بلافاصله ارتباط را آغاز نمایید.

## چرا لومینا چت؟

امروزه بخش بزرگی از ارتباطات آنلاین به سرویس‌ها و پلتفرم‌های متمرکز وابسته است. لومینا چت تلاش می‌کند یک جایگزین ساده و سبک ارائه دهد که توسط افراد، دوستان، خانواده‌ها، مدارس، انجمن‌ها و جوامع محلی قابل راه‌اندازی و مدیریت باشد.

ایده اصلی پروژه ساده است:

> ارتباطات باید تا حد امکان در اختیار کاربران و جوامع باشد، نه صرفاً سرویس‌های متمرکز.

لومینا چت می‌تواند برای گروه‌های دوستانه، انجمن‌ها، شبکه‌های محلی، تیم‌های کوچک، مدارس، سازمان‌ها یا هر جامعه‌ای که به یک بستر ارتباطی مستقل و ساده نیاز دارد مورد استفاده قرار گیرد.

## راه‌اندازی سریع

1. فایل ZIP پروژه را دانلود کنید.
2. فایل‌ها را روی هاست، سرور لینوکسی، VPS یا وب‌سرور محلی خود استخراج نمایید.
3. مراحل موجود در فایل `help.txt` را دنبال کنید.
4. چتروم یا گروه خود را ایجاد کرده و دوستان یا اعضای جامعه خود را دعوت نمایید.
5. پس از پایان راه‌اندازی، برای امنیت بیشتر فایل `help.txt` را حذف کنید.

## چشم‌انداز پروژه

لومینا چت تنها یک چتروم ساده نیست.

این پروژه تلاشی برای ارائه یک بستر ارتباطی سبک، مستقل و قابل استقرار در هر محیطی است؛ بستری که به کاربران اجازه می‌دهد بدون وابستگی کامل به سرویس‌های بزرگ و متمرکز، ارتباطات خود را مدیریت کنند.

سادگی، پرتابل بودن، خودمیزبانی (Self-Hosting) و مالکیت بر زیرساخت ارتباطی، از مهم‌ترین اهداف این پروژه هستند.
